## Getting Started Playbook

Launch Sequel Pro and use the connection window to enter host, username, password, and database, optionally setting up an SSH tunnel for remote servers. Save it as a favorite so it lives in the sidebar.

Connect and the table list appears on the left. Click a table to view its content, switch to the structure tab to change columns, or open the custom query tab to run SQL directly against the active connection.
